# Kantin Multi-Tenant - Laravel 13

Aplikasi Sistem Informasi Kantin Multi-Tenant berbasis Laravel 13, Livewire v4, dan Laravel Reverb.

## Prerequisites
- **PHP** >= 8.4
- **MariaDB** >= 11.4 / MySQL >= 8.0
- **Redis Server** (Port 6379)
- **Node.js** >= 20.x & NPM
- **Composer** >= 2.x
